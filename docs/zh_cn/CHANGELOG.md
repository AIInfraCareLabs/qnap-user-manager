# Changelog

[English](../../CHANGELOG.md) | [中文文档目录](README.md) | [中文 README](../../README-zh_cn.md)


## 0.5.0 — 2026-11-26

- 默认文档改为英文，新增中文 README 与中文 docs，建立双语导航。
- 源码包收录两种语言。
- 本地 dashboard 改为收集完整的用户、组和共享目录清单，不再只显示第一页。
- 移除组成员与用户所属组读取及其回读校验中的 `lower`/`upper`；NAS 对这些操作忽略它们。
- 通过声明的 `[lower, upper)` 契约对共享目录枚举进行分页。
- 记录 QTS 5.1.9.2954 的写入验证（24 项检查）以及成员与共享目录分页结论。

## 0.4.0 — 2026-09-13

- 可安装 wheel / sdist，内置精确固件契约和公开 profile 加载器。
- 原生登录、会话检查、注销撤销验证与安全 SID 文件；CLI 登录、退出和契约查询。
- 用户、组、共享目录、共享权限 CRUD，成员变更、密码重置及用户禁用/启用。
- 写后状态验证、显式与继承权限区分、保留未变更元数据、禁止自动重试写请求。
- 完善离线回归、包安装验证、开发记录及示例。

仅验证 QTS 5.1.9.2954；0.5.0 已准备但尚未发布，0.4.0 仍是最新 PyPI 版本。
